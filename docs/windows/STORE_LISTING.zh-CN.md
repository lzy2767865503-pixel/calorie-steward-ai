# 卡路里管家（LAI ZEYU 发布）

类别：健康与健身

作者与发布者：**LAI ZEYU（来泽宇）**

卡路里管家是一款本地优先的 Windows 饮食记录工具。选择餐食图片，由你自行配置的 AI 服务估算可见食物与营养范围，人工复核后把结构化记录保存在电脑上。

主要特点：

- 无账户、无广告、无开发者分析追踪，也不内置 API Key；
- API 凭据由 Windows 系统保护；
- 餐食图片只在内存中重编码，移除 EXIF/GPS，默认且强制不保留；
- 发送图片或聚合报告前明确展示并确认目标服务；
- 公开营养参考覆盖度和不确定范围；
- 完整中英文界面；
- 本地 JSON 导出与一键删除全部本地数据。

AI 识别和 AI 报告需要联网，并需要用户自己提供受支持的 AI 服务或组织网关。该服务自身的条款、数据保留规则和费用由用户确认。已保存的结构化记录与摘要主要保留在本机。

本软件用于日常记录和饮食结构观察，不是医疗器械、诊断、实验室热量检测，也不能替代医生或营养师。
